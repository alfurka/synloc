Mixed-type clusterCov export¶

synloc.mixed_cluster provides a separate, versioned parameter-only format. The existing numeric-only clusterCov and ClusterCovSampler APIs and archives are unchanged. The caller must supply a fixed, public schema obtained independently of the input records: public integer category dictionaries and public numeric bounds and public code descriptions, not observed categories, sample extrema, learned scaling parameters, source records, identifiers, or audit evidence. The model cannot verify that the caller’s purportedly public metadata is actually public. Supply one person per row, only original model variables, no IDs, and no missing, nonfinite, unknown-category, out-of-bounds or constraint-violating inputs.

The complete schema is a JSON-compatible dictionary with exactly version (integer 1), columns (ordered list), and constraints (list). Each category has exactly name, kind: category, ordered integer categories and corresponding public labels. Each numeric column has exactly name, kind (integer or continuous), min and max. Integer bounds must be finite integers; continuous bounds may be null for unbounded support. Use null bounds for signed earnings if the intended decoder must leave earnings untouched. Use public, dictionary-supported nonnegative and upper bounds for hours and counts. A constraint is exactly {"kind": "less_equal", "left": "children_q1", "right": "household_size_q1"}; it may only link compatible integer columns, with at most one constraint per left column and no chains. A left minimum must not exceed the right minimum. Unknown fields, kinds, transforms and versions are rejected. Category codes, integer limits and numeric bounds are restricted to exactly representable integers/finite values no larger than 2^53 in magnitude. The encoded dimension is limited to 512; the archive metadata and arrays have size limits. Names are simple unique identifiers, not source labels.

Example with hypothetical, independently public definitions:

from synloc.mixed_cluster import MixedClusterCovModel, MixedClusterCovSampler

schema = {
    "version": 1,
    "columns": [
        {"name": "sex", "kind": "category", "categories": [1, 2], "labels": ["Male", "Female"]},
        {"name": "age", "kind": "integer", "min": 18, "max": 64},
        {"name": "earnings", "kind": "continuous", "min": None, "max": None},
    ],
    "constraints": [],
}
model = MixedClusterCovModel(data, schema, n_clusters=8, size_min=100).fit_model()
report = model.clearance_report()  # confidential internal diagnostics
scores = model.raw_scores(100, random_state=42)
generated, interventions = model.decode(scores, return_diagnostics=True)
model.export_model("mixed.npz", reviewed=True)
sampler = MixedClusterCovSampler.load("mixed.npz")
# This is exactly the same decoded draw as generated above.
reloaded = sampler.sample(100, random_state=42)

One-hot columns are in schema and dictionary order, including unobserved codes. Gaussian means and covariances are in encoded original units; standardization is used only for clustering. A category block decodes by argmax, with ties resolved by the first public dictionary code. Constant dimensions remain constant. Integers round to nearest with ties to even and are clipped to public bounds; continuous values are clipped only where explicit public bounds exist. The constraint lowers its left value to the right value when necessary. There are no other implicit employment, earnings or household adjustments. raw_scores and decode(..., return_diagnostics=True) expose latent values and counts of invalid one-hot scores, ties, raw and decoded bound/integer violations, rounding, clipping and cross-constraint interventions. sample(..., return_diagnostics=True) returns the same pair. These are synthetic draw diagnostics, not the confidential internal clearance report.

The NPZ has exactly a scalar version, scalar JSON metadata, weights, encoded means and covariances. Loading disables pickle and validates metadata, array shapes, finite parameters, positive normalized weights and positive-semidefinite covariances. A fresh process needs no source records. An archive remains a potential disclosure: mixture weights, means and covariance entries can reveal information. Export requires reviewed=True as a research acknowledgement, and the existing required contributor-count gate applies. This is neither a privacy guarantee nor regulatory approval; the gate does not assess all risks. Perform independent disclosure review, including rare groups, household relationships, covariance entries and repeated sampling, before any release.

class synloc.mixed_cluster.MixedClusterCovModel(data, schema, n_clusters=8, size_min=None, normalize=True)[source]¶

Fit clusterCov to one-hot categories under a caller-supplied public schema.

Rows must be persons, not identifiers. Bounds/dictionaries must be fixed independently of the fitted data, reviewed as public, and supplied explicitly. Numeric scaling affects clustering only. The source and internal clearance diagnostics must not be included in a released archive.

class synloc.mixed_cluster.MixedClusterCovSampler(means, covariances, weights, schema)[source]¶

Decode draws from a validated, self-contained mixed parameter archive.

Use load() to read an NPZ. raw_scores exposes the joint latent draws and decode optionally reports counts of each intervention.

property columns¶

Immutable decoded output column names.

decode(raw_scores, *, return_diagnostics=False)[source]¶

Decode scores, optionally returning per-rule record counts.

Argmax ties use first dictionary entry; integers use NumPy ties-to-even rounding, then public bounds. Cross-constraints lower the left value.
