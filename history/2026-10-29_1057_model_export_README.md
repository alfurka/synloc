# Public SIPP model-export experiment

This experiment prepares a balanced working-age panel from the public 2018 SIPP release (reference year **2017**) and evaluates parameter-only `clusterCov` models. The eight model features are four quarterly earnings sums and four quarterly means of monthly average weekly-hours rates, in original units. The experiment is unweighted and does not establish privacy clearance for confidential data.

## Prepare the input

Run commands from the repository root with the repository environment active. Set `SIPP_INPUT` to the supplied `pu2018.csv.gz` file, or obtain the pipe-delimited GNU/Linux file from the [Census 2018 SIPP release page](https://www.census.gov/programs-surveys/sipp/data/datasets/2018-data/2018.html). The raw file need not be copied into this repository. Do not commit raw files or generated data.

```sh
python replication/model_export/prepare_sipp.py \
  --input "$SIPP_INPUT" \
  --output replication/model_export/prepared
```

`--chunksize` optionally changes the default 25,000-row input chunks. Preparation needs only pandas, NumPy, and the Python standard library. It reads ten selected columns, validates the observed panel and wave, and outputs:

| File | Contents |
| --- | --- |
| `prepared/wide.csv` | Numeric `earnings_q1` … `earnings_q4`, `hours_q1` … `hours_q4`, no IDs. |
| `prepared/long.csv` | Internal quarterly `person_id,quarter,y,h` diagnostic table. |
| `prepared/metadata.json` | Source checksum, selected fields, exclusions, zero fills, units, software versions, and limitations. |

The selected inputs are `SSUID`, `PNUM`, `SPANEL`, `SWAVE`, `MONTHCODE`, `RIN_UNIV`, `TAGE`, `RMNUMJOBS`, `TPEARN`, and `TMWKHRS`. Retained people have 12 unique months, are in the survey frame and age **18–64 throughout**, and have complete valid outcomes after documented no-job structural-zero handling. Observed negative earnings are retained because business losses are valid, not treated as invalid or clipped. There are no log transforms.

[Data-source and preprocessing details](DATA_PREPARATION.md) document the exact universes, actual hours definition, aggregation, sample selection, and bias. [`sipp_source_metadata.json`](sipp_source_metadata.json) records compact official schema/dictionary excerpts and source links. Prepared sample sizes are generated by the run, not inferred from the inspected small sample.

## Run the experiment

```sh
python replication/model_export/run_experiment.py \
  --input replication/model_export/prepared/wide.csv \
  --output replication/model_export/results
```

The default grid has **12 configurations**: cluster-size targets 20, 50, and 100 crossed with noise levels 0, 10, 50, and 100; each configuration uses **10 synthetic replications**. See the driver's `--help` for available controls. Comparisons concern this selected public-use panel and parameter-only sampling; they are not population estimates or evidence of formal privacy guarantees.

The default `prepared/` and `results/` directories are ignored, as are generated CSV and NPZ files in this directory. Keep any custom output locations ignored as well. Internal IDs, sample-flow metadata, diagnostic tables, and raw-data comparisons are not part of the parameter-only export. Export review acknowledgement is separate from mechanical model validity; public input data alone does not establish privacy approval for arbitrary fitted models.
